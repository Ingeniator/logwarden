# logwarden v0.1.0

**Status:** Released 2026-11-17 · commit `c0382c8`

First version: a command-line check of JSON logs against the ai-suite logging standard (ADR-0001).

## What's in it

- `bin/logwarden check <logs.jsonl>` converts each log line into a sample for OTel Weaver
  `registry live-check` and prints the number of violations per rule. It exits with code 1
  when it finds a violation.
- Rules (Rego): `adr_banned_synonym`, `adr_semconv_prefix`, `adr_missing_required`,
  `adr_environment_value`, `adr_event_name`, `adr_failure_context`. Weaver adds
  `missing_attribute` and `deprecated`.
- Registry: OTel semconv v1.45.0 plus shared fields (`logger`, `request_id`, `duration_ms`,
  `upstream_request_id`, `upstream_error_message`).
- GitHub Action (`uses: Ingeniator/logwarden@v0.1.0`), and `make test` / `make check`.
